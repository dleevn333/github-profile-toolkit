# Contributing to GitHub Profile Toolkit

Thank you for your interest in contributing to **GitHub Profile Toolkit**! We welcome all community contributions, bug reports, and suggestions.

---

## How to Contribute

### 1. Reporting Bugs
- Search existing issues to ensure the bug hasn't already been reported.
- Open a new issue with a clear title and description, including steps to reproduce and system details.

### 2. Suggesting Enhancements
- Open an issue explaining the proposed feature and why it would be beneficial.

### 3. Pull Request Workflow
1. Fork the repository and create your feature branch:
   ```bash
   git checkout -b feature/amazing-feature
   ```
2. Write clean, readable Python code adhering to PEP 8 standards.
3. Keep external dependencies minimal or rely on standard library modules.
4. Run tests before submitting:
   ```bash
   python -m unittest discover tests
   ```
5. Commit your changes with descriptive messages:
   ```bash
   git commit -m "feat: add support for organization profiles"
   ```
6. Push to your branch and open a Pull Request against the `main` branch.

---

## Code of Conduct

Please maintain a friendly, inclusive, and respectful tone in all discussions and code reviews.
